How it works

Four steps from browser to spec.

Record the flow

Open the side panel, hit record, and test your app the way you normally would.

Add assertions

Check text, visibility, values or CSS, such as toHaveCSS, from the panel or a right-click.

Re-run it

Re-run the steps in a new tab. A failure shows its screenshot, console errors, trace and a ready bug report.

Generate or copy

Connect your repo and generate framework code, or copy the plain Playwright code. Then run npx playwright test.

FAQ

Questions, answered.

Is TestFit free?

Yes. TestFit is free to install from the Chrome Web Store, with no sign-up and no credit card. If you generate code with a hosted AI provider, that provider bills your own API key at its usual rates. A local model costs nothing.

Do I need an AI API key?

Only to generate framework code. Recording, assertions, re-runs, schedules and copying the plain Playwright code need no key. To generate code, add a key for Anthropic, OpenAI or Google Gemini, or point TestFit at a local model such as Ollama or LM Studio, which needs no key.

How is this different from Playwright's codegen?

Codegen records raw locators on the page. TestFit maps your steps to your existing page objects, fixtures and coding guidelines, so the output matches how your team already writes tests.

We don't have a framework yet. Can I still use it?

Yes. Without a repo, TestFit generates standard Playwright Page Object Model code: page objects in pages/ and specs in tests/, with stable locators and your assertions. It's a good start for a framework.

I'm not a coder. Will this work for me?

Yes. Recording a flow and adding assertions needs no code. You can hand the generated spec to an SDET or developer to add to the repo.

Is my data safe?

Recordings, results and your settings stay in your browser. TestFit has no server and no analytics. Only when you generate code or write a bug report with AI does it send a request, straight from your browser to the provider you chose. You can preview that request first, emails and phone numbers are replaced with placeholders, and passwords are never sent. See the privacy policy.

Why does TestFit need the debugger permission?

TestFit records and re-runs tests with Playwright, which controls a tab through Chrome's DevTools Protocol. It attaches only to the tab you record or re-run, and Chrome shows its "started debugging this browser" banner while it does.

Which frameworks are supported?

TestFit generates Playwright tests in TypeScript.
