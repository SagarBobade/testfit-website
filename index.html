FAQ

Questions, answered.

Is TestFit free?

Yes. TestFit is free to install from the Chrome Web Store, with no sign-up and no credit card.

Do I need an OpenAI or Gemini API key?

No. TestFit creates a prompt that you paste into any public model, like ChatGPT, Gemini or Claude, on their free plans. You can compare outputs from several models and keep the best one.

How is this different from Playwright's codegen?

Codegen records raw locators on the page. TestFit maps your steps to your existing page objects, fixtures and coding guidelines, so the output matches how your team already writes tests.

We don't have a framework yet. Can I still use it?

Yes. Without a profile, TestFit generates clean Playwright TypeScript with stable locators and assertions, plus page object snippets you can build a framework from.

I'm not a coder. Will this work for me?

Yes. Recording a flow and adding assertions needs no code. You can hand the generated spec to an SDET or developer to add to the repo.

Is my data safe?

Recordings and your framework profile stay in your browser. TestFit doesn't send them to any server. You decide what goes into an AI tool when you paste the prompt. See the privacy policy.

Which frameworks are supported?

TestFit generates Playwright tests in TypeScript.
